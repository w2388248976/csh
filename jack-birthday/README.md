# JACK · honey 的生日小屋

为陈思罕 JACK（2011 年 11 月 8 日生日）制作的可预览生日网页。清新薄荷绿 #4CE8CC，暖木色 #AD9C84，奶油薄荷白 #EAFEF0。

## 启动预览

需要 Node.js 24 或更新版本，不需要安装依赖：

```powershell
cd D:\gptcode\jack-birthday
node server.mjs
```

访问 http://127.0.0.1:4173 。Three.js 0.180.0 已固定版本存放于 `dist/vendor`，没有运行时 CDN 或外部字体依赖。许可证随源码附带。

## 已实现

- 真正的 WebGL 3D 玩具小屋，可拖动有限角度，重置视角，触摸操作。
- 电吉他可弹奏，金毛、腊肠、灰猫可点击，收集「生 / 日 / 快 / 乐」四个彩蛋。
- 点击礼物盒打开，出现草莓生日蛋糕，再点击打开留言表单。
- 匿名昵称、8 个表情头像、祝福内容提交；保存成功后可长按 1 秒吹蜡烛，或主动授权麦克风检测吹气。
- 麦克风只在本机分析音量，不录音、不上传；关闭窗口、完成或 15 秒超时即释放麦克风。音量检测也可能被其他响声触发。
- 金粉色烟花、祝福揭晓、交互音效；《太阳 (Live)》已接入 QQ 音乐官方外链播放器（TF家族-陈思罕，歌曲 ID 610325043）。右上角打开播放器后手动点击播放，可继续探索小屋；关闭播放器会停止播放。播放可用性取决于 QQ 音乐，另有官方歌曲页入口。不下载或代理歌曲音频。
- SQLite 服务端保存，按最新顺序显示，6 条一页，加载更多，总数不包含演示卡片。
- 昵称 1–16 个 Unicode 字符，祝福 2–200 字符；服务端基础词语过滤、拒绝链接/HTML、30 秒/IP 限流、24 小时相同内容去重、幂等提交。
- 移动端单列布局、键盘物品按钮、对话框焦点约束、减少动态效果偏好支持。

## 真实数据与演示数据

首次启动创建 `data/wishes.sqlite`。用户提交经 API 成功返回后才显示成功，数据持久保存在服务器，不使用 localStorage 假装共享。刷新、关闭浏览器、重启服务器都不会删除数据库中的祝福。页面内置 6 条演示留言，每条明确标注，既不会写入数据库，也不会计入总数。

**目前是本机预览，还没有公共网址。** 同一服务实例的所有浏览器共享同一数据库；其他设备只有能访问该服务实例时才能看到数据。预览监听 127.0.0.1，不自动向局域网或互联网开放。

## 公开部署还需要什么

1. 选择支持 Node.js 24 的持续运行服务器，执行 `node server.mjs`，由进程管理器维持运行。没有外部数据库账号要求。
2. 配置 `HOST=0.0.0.0`、`PORT`（默认 4173），以 HTTPS 反向代理提供域名；HTTPS 也是远程麦克风权限的要求。
3. 将 `DB_PATH` 指向持久磁盘的 SQLite 文件，并定期使用 SQLite backup API 或停机一致性备份。不能把数据库留在临时容器磁盘。
4. 本实现直接按 socket IP 限流，**不会信任访客提交的 X-Forwarded-For**。反向代理部署前需要按所选平台实现可信代理 IP 提取，否则所有人可能共用一个限流额度。多实例部署需要迁移到共享数据库及共享限流存储，不能各自使用独立 SQLite 文件。
5. 上线前补充管理员删除/举报、内容审核服务和验证码。现有词表是基础过滤，不是完备审核；不要把它描述成能防止所有不当内容。建议为内容审核接入服务端待审状态，并按站点需求确定保留期限。
6. 本项目未注册或发布 Sites 站点。Sites 的 Cloudflare Workers 环境不直接运行 Node 的 `node:sqlite`；如选 Sites 部署，需要将 API 迁移到 D1 并配套迁移文件。当前服务适合 Node 主机或容器部署。

无用户账号；昵称不是身份验证。页面按文本节点渲染留言，SQL 使用参数化查询。数据库不保存明文 IP，仅保存其 SHA-256 哈希用于限流（哈希仍应按访客相关数据管理）。
